# Fiza Zohaib — Portfolio Website

A responsive multi-page portfolio built with HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About
- `skills.html` — Skills
- `projects.html` — Interactive project gallery
- `experience.html` — U Devs internship and certificate
- `education.html` — Education
- `contact.html` — Contact placeholders

## Working projects
- `projects/taskflow/index.html` — Task manager with create, complete, delete, filters, due dates, priorities, and local storage.
- `projects/smart-home/index.html` — Smart home interface with device toggles, scenes, thermostat, activity log, and local storage.
- `projects/devflow-crm/index.html` — CRM with contact/opportunity create, edit, delete, search, stage filters, pipeline summary, and CSV export.

These are functional browser-based portfolio projects. Their data is stored locally in the browser; they are not client deployments or server-backed production systems.

## Run in VS Code
1. Extract the ZIP.
2. Open the extracted `fiza_zohaib_portfolio_pro` folder in VS Code.
3. Install **Live Server** by Ritwick Dey.
4. Right-click `index.html` → **Open with Live Server**.

## Contact details
Open `contact.html` and replace `YOUR_EMAIL@example.com`, `YOUR_LINKEDIN_URL`, `YOUR_GITHUB_URL`, and `YOUR_WHATSAPP_NUMBER`.
Also replace `YOUR_EMAIL@example.com` in `assets/script.js` with your real email.
